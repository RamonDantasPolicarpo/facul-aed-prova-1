Folha de Cola — Back-End (.NET / EF Core)

Revisão de 5 minutos antes da prova. Tudo ancorado no que você já conhece de Java.

1. Web API & DI (Pré-Unidade 4)

  • Minimal API: rotas no Program.cs (app.MapGet).
  • Controllers: classes dedicadas ([ApiController], tipo @RestController).
  • DI (AddDbContext): container cria e injeta no construtor (tipo @Autowired), gerenciando ciclo de vida e descarte.

2. Hash & Segurança

  • Criptografia: mão dupla (reversível com chave — ex.: AES).
  • Hash: mão única (irreversível), tamanho fixo, efeito avalanche → garante integridade.
  • MD5 (128 bits): ❌ inseguro (colisões).
  • SHA-256 (256 bits): ✅ seguro para integridade.
  • Senhas: usar bcrypt / Argon2id (salt + work factor).

4. ORM & DbContext

  • Impedância O/R: choque Objeto ↔ Tabela SQL.
  • ORM: EF Core (C#) ↔ Hibernate/JPA (Java).
  • Scoped: 1 por requisição HTTP (✅ padrão).
  • Singleton: 1 global (❌ proibido: não é thread-safe + vazamento de memória).
  • DeleteBehavior.Restrict: bloqueia excluir pai com filhos (erro FK). Cascade apaga tudo.

5. Change Tracker (5 Estados)

  • Detached → não rastreada (AsNoTracking)
  • Unchanged → lida do banco, sem mudanças
  • Added → Add() → gera INSERT
  • Modified → propriedade alterada → UPDATE
  • Deleted → Remove() → gera DELETE

6. Mapeamento (Slide 35)

  • Convenções: Id = PK, CategoryId = FK.
  • Data Annotations: [Required], [Range] → nos DTOs (HTTP).
  • Fluent API: OnModelCreating → schema, índices, HasPrecision, HasOne/WithMany, OnDelete.

7. LINQ, N+1 & Performance

  • IQueryable: Where() antes de ToListAsync() filtra no SQL; depois filtra em memória.
  • AsNoTracking(): usar só em leituras (GET); nunca em PUT/DELETE.
  • N+1: Lazy Loading no loop faz 1 + N queries.
  • Solução: Include() (Eager, 1 JOIN) ou Select() (Projeção DTO, evita overfetching).

8. Migrations & Transações

  • dotnet ef migrations add Nome → gera Up()/Down().
  • dotnet ef database update → aplica no banco.
  • __EFMigrationsHistory: tabela com migrations aplicadas.
  • 1 SaveChangesAsync: transação implícita.
  • Vários SaveChangesAsync: BeginTransactionAsync + CommitAsync / RollbackAsync (atomicidade).

9. DTOs, Erros & Padrões

  • DTOs: evitam ciclos JSON, overfetching, overposting e acoplamento.
  • [ApiController]: valida DTO antes do método → 400 ValidationProblemDetails.
  • IExceptionHandler: centraliza erros inesperados (não vaza stack trace).
  • Repository + UoW: DbSet<T> + DbContext já fazem esse papel.
