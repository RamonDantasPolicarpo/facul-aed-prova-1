Árvores e Árvore Binária de Busca (ABB)

Da lista linear à hierarquia — como a ABB organiza dados e por que a ordem de chegada muda tudo.

🌳 Lista vs Árvore

A principal diferença entre uma lista e uma árvore é a organização:

  • Lista: estrutura linear (um elemento atrás do outro, em fila única).
  • Árvore: estrutura hierárquica (um nó pai se ramifica em nós filhos, como pastas no sistema ou organograma).

🦴 Anatomia de uma Árvore

TermoSignificado
RaizO primeiro nó no topo da árvore (não tem pai).
ArestaA ligação direta (linha/ponteiro) entre dois nós consecutivos (pai ↔ filho).
FolhaUm nó na ponta que não tem filhos (esq e dir são None).
ProfundidadeNúmero de arestas no caminho entre a raiz e o nó (raiz tem profundidade 0).
AlturaMaior profundidade da árvore (distância da raiz até a folha mais baixa).

🔍 Árvore Binária de Busca (ABB)

Uma ABB (ou BST — Binary Search Tree) é uma árvore onde cada nó tem no máximo 2 filhos e obedece sempre à mesma regra de ouro:

Regra de Ouro da ABB Tudo na subárvore esquerda é menor que o nó atual.
Tudo na subárvore direita é maior que o nó atual.

Na implementação padrão vista em aula (Python), valores duplicados são ignorados na inserção para evitar duplicidade.

Exemplo passo a passo: inserindo 8, 3, 10, 1, 6, 14

  1. 8 chega na árvore vazia → vira a raiz.
  2. 3 < 8 → vai para a esquerda do 8.
  3. 10 > 8 → vai para a direita do 8.
  4. 1 < 8 (esq) e 1 < 3 (esq) → esquerda do 3.
  5. 6 < 8 (esq) e 6 > 3 (dir) → direita do 3.
  6. 14 > 8 (dir) e 14 > 10 (dir) → direita do 10.
[8] ← Raiz (profundidade 0) / \ [3] [10] ← Arestas ligam pai e filho (profundidade 1) / \ \ [1] [6] [14] ← Folhas: 1, 6 e 14 (sem filhos, profundidade 2)
🔶 Conexão com Java Em Java, cada nó seria uma classe Node { int val; Node left, right; } (onde None em Python equivale a null em Java). A coleção TreeSet do Java usa uma árvore de busca balanceada por baixo dos panos!

💻 Código Python Completo (Nó, Inserção, Busca e Contagem)

Para o código rodar de verdade, primeiro definimos a classe No (igual a um class Node em Java, com ponteiros esq e dir):

class No:
    def __init__(self, val):
        self.val = val
        self.esq = None
        self.dir = None

def inserir(no, valor):
    if no is None:
        return No(valor)
    if valor < no.val:
        no.esq = inserir(no.esq, valor)
    elif valor > no.val:
        no.dir = inserir(no.dir, valor)
    # se valor == no.val, ignora (evita duplicidade!)
    return no

def buscar(no, valor):
    if no is None:          # Chegou no vazio → valor NÃO encontrado!
        return False
    if valor == no.val:
        return True
    if valor < no.val:
        return buscar(no.esq, valor)
    return buscar(no.dir, valor)

def contar_nos(no):
    if no is None:
        return 0
    return 1 + contar_nos(no.esq) + contar_nos(no.dir)  # Soma as subárvores + 1

# Testando na prática:
raiz = None
for x in [8, 3, 10, 1, 6, 14]:
    raiz = inserir(raiz, x)

print(buscar(raiz, 6))     # True
print(buscar(raiz, 99))    # False
print(contar_nos(raiz))    # 6
💡 Atenção para a prova Se quiser saber se um valor está na ABB, a primeira função a implementar/chamar é buscar. Se ela chega em None e retorna False, significa que o valor não foi encontrado.

⚠️ ABB Equilibrada vs ABB Degenerada

A velocidade da ABB depende da sua altura:

  • Inserções variadas (equilibrada): os dois lados crescem juntos. A altura fica próxima de log₂(N) → busca muito rápida.
  • Valores já ordenados (ex: 1, 2, 3, 4, 5): cada novo valor é maior que o anterior e vai sempre para a direita. A altura aumenta muito (fica próxima de N).
ABB Equilibrada (altura ≈ log N) ABB Degenerada: 1, 2, 3, 4 (altura ≈ N) [3] [1] / \ \ [1] [4] [2] \ \ \ [2] [5] [3] \ [4] ← igual a uma lista encadeada!

Quando a ABB fica degenerada (inclinada para um lado só), sua altura é próxima de N e ela se comporta como uma lista encadeada — busca e inserção caem para O(N).

🎯 Prática Rápida (Estilo Kahoot 5)

1. Qual afirmação descreve corretamente a principal diferença entre uma lista e uma árvore?

  • Árvore organiza dados de forma hierárquica
  • Árvore guarda apenas números inteiros positivos
  • Lista não permite inserir novos elementos
  • Lista usa menos memória em qualquer caso
✅ Exato! Lista é linear (1D); árvore é hierárquica (pai → filhos).
❌ Lembre: lista é linear e árvore é hierárquica.

2. O que acontece com a altura de uma ABB se os valores chegarem já ordenados crescentemente?

  • A altura aumenta muito e vira lista
  • A altura diminui pela metade automaticamente
  • Os valores duplicados corrigem o equilíbrio
  • A raiz muda a cada nova inserção
✅ Isso! Todo nó vai para a direita, a altura fica próxima de N (árvore degenerada).
❌ Valores ordenados fazem todos os nós irem para um único lado, aumentando muito a altura.

3. Ao inserir 8, 3, 10, 1, 6, 14 em uma ABB vazia, onde fica o valor 6?

  • Na subárvore esquerda, filho direito de 3
  • Na subárvore direita, filho esquerdo de 10
  • Na subárvore esquerda, filho esquerdo de 3
  • Na subárvore direita, filho direito de 14
✅ Perfeito! 6 < 8 (vai pra esquerda), depois 6 > 3 (vai pra direita do 3).
❌ Rastreie: 6 < 8 (esquerda do 8), depois compara com 3: 6 > 3 (direita do 3).

4. Se a função buscar retorna False ao chegar em um nó None, o que isso significa?

  • O valor procurado não foi encontrado
  • A árvore inteira está vazia agora
  • O nó atual é uma folha
  • O valor existe em duplicidade lá
✅ Certo! Chegar em None quer dizer que o caminho acabou sem achar o valor.
❌ None na busca significa que não há mais para onde descer: valor não encontrado.
